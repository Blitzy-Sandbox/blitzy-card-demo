# =====================================================================
# COACTUPC (Account Update; CICS transaction CAUP) Golden-Record
# Scenario Driver Script
# =====================================================================
#
# Purpose: scenario specification consumed by the JUnit 5 test class
# com.blitzy.carddemo.tests.golden.CoActUpCGoldenTest. Each SCENARIO
# block simulates one CICS pseudo-conversation cycle (RECEIVE MAP ->
# process -> SEND MAP) against the Java translation of COBOL program
# app/cbl/COACTUPC.cbl. The harness asserts byte-for-byte parity with
# captured COBOL outputs in sibling files acctdata.txt, custdata.txt,
# bms_output.txt, stdout.txt.
#
# This is a SPECIFICATION. Mock READ/REWRITE records and commarea hex
# bytes are '<...>' placeholders to be captured per the procedure in
# java/MIGRATION_NOTES.md section 1.6. Until captures are committed,
# CoActUpCGoldenTest is @Disabled per AAP section 0.6.11.
#
# Authority:
#   AAP 0.1.1  -- byte-for-byte parity mandate
#   AAP 0.4.1  -- COACTUPC translation; SYNCPOINT ROLLBACK
#                 IMPLEMENTATION DECISION (try/finally + compensating
#                 writes)
#   AAP 0.6.11 -- golden-record harness PR gate; @Disabled until
#                 captures committed
#   AAP 0.7.1  -- Minimal Change Clause; verbatim message preservation
#   AAP 0.7.2  -- PAN masking in logs: '************<last4>'
#   AAP 0.7.5  -- capture procedure in
#                 java/MIGRATION_NOTES.md section 1.6
#
# Behavior recap: COACTUPC services CICS transaction CAUP via BMS
# mapset COACTUP / map CACTUPA (app/bms/COACTUP.bms). 7-state ACUP
# machine (ACUP-DETAILS-NOT-FETCHED, ACUP-SHOW-DETAILS, ACUP-CHANGES-
# MADE, ACUP-CHANGES-NOT-OK, ACUP-CHANGES-OK-NOT-CONFIRMED, ACUP-
# CHANGES-OKAYED-AND-DONE, ACUP-CHANGES-OKAYED-BUT-FAILED). 4 valid
# AIDs (L905-L916): ENTER (always), PF03 (always; XCTL to LIT-MENUPGM
# 'COMEN01C'), PF05 (ACUP-CHANGES-OK-NOT-CONFIRMED only), PF12 (NOT
# ACUP-DETAILS-NOT-FETCHED); others coerced to ENTER via 'SET CCARD-
# AID-ENTER TO TRUE'. 9000-READ-ACCT chain: CXACAIX (50B) -> ACCTDAT
# (300B) -> CUSTDAT (500B). PF5 save: paired EXEC CICS REWRITE on
# ACCTDAT (L4066) and CUSTDAT (L4086); on CUSTDAT failure (L4095-
# L4103) EXEC CICS SYNCPOINT ROLLBACK fires at L4100 -- the SOLE-IN-
# CODEBASE ROLLBACK across all 28 COBOL programs, pinned down by
# scenario 9 below. 9700-CHECK-CHANGE-IN-REC (L4109+) is the
# optimistic-concurrency guard.
#
# Directive Reference (parser grammar in CoActUpCGoldenTest):
#   SCENARIO:        <id>                  Begin scenario block (snake_case)
#   DESCRIPTION:     <text>                One-line human description
#   STATE: <commarea-state-id>  -- entry | none |
#       reentry_details_not_fetched | reentry_show_details |
#       reentry_changes_ok_not_confirmed |
#       reentry_changes_okayed_and_done | reentry_changes_failed
#   EIBCALEN: <int>             -- DFHCOMMAREA length; 0 = fresh entry
#   COMMAREA_HEX: <hex>         -- Inbound commarea; cont lines start '+'
#   MAP_INPUT: <FIELD> <VALUE>  -- One BMS field; quote VALUE if spaces;
#                                  empty VALUE = LOW-VALUES (not sent)
#   AID: <key>                  -- ENTER | PF1..PF24 | CLEAR | PA1 | PA2
#                                  | PA3
#   MOCK_READ: <file> <key> <resp> <resp2> [<hex-record>]
#                                  file in {CXACAIX, ACCTDAT, CUSTDAT};
#                                  resp in {NORMAL, NOTFND, IOERR,
#                                  LENGERR}; hex required when NORMAL
#   MOCK_REWRITE: <file> <resp> <resp2>
#                                  file in {ACCTDAT, CUSTDAT}; resp in
#                                  {NORMAL, NOTOPEN, INVREQ, IOERR}
#   EXPECT_XCTL: <program>      -- Assert XCTL was issued
#   EXPECT_SEND_MAP: <map> <mapset>
#                                  Assert SEND MAP was issued
#   EXPECT_CURSOR: <field>      -- Assert cursor field
#   EXPECT_FIELD: <FIELD> <VALUE> <ATTR>
#                                  ATTR is a comma-separated set like
#                                  BRT,RED,FSET,UNPROT,UNDERLINE
#   EXPECT_MSG: INFOMSG|ERRMSG <text>     Quote text with "..."
#   EXPECT_INFOMSG_ATTR: DRK | BRT        Assert INFOMSGA attribute
#   EXPECT_RESP: NORMAL | ABCODE_9999     Assert program RESP code
#   EXPECT_ABCODE: <4-char>     -- Assert EXEC CICS ABEND
#   EXPECT_READ: <file> <count> -- Assert plain READ count
#   EXPECT_READ_UPDATE: <file> <count>    Assert READ UPDATE count
#   EXPECT_REWRITE: <file> <count>        Assert REWRITE count
#   EXPECT_SYNCPOINT: COMMIT|ROLLBACK <count>
#                                  ROLLBACK sole-in-codebase; scenario
#                                  9 only
#   EXPECT_ACCTDAT_UNCHANGED    -- acctdata bytes == source fixture
#   EXPECT_CUSTDAT_UNCHANGED    -- custdata bytes == source fixture
#   EXPECT_ACCTDAT_CHANGED: <recno> <off> <len> <hex>  In-place change
#   EXPECT_CUSTDAT_CHANGED: <recno> <off> <len> <hex>  In-place change
#   EXPECT_RETURN_COMMAREA_HEX: <hex>     Outbound commarea bytes
#   MASKED_PAN_LAST4: <lastfour>          PAN logged as
#                                         '************<lastfour>'
#   END_SCENARIO                          Explicit scenario end
#
# Encoding: ASCII only (no Unicode em-dash, ellipsis, curly quotes).
# LF line endings only. Spaces only (no tabs). Single LF at EOF. Hex
# strings use lowercase a-f without 0x prefix. Placeholder '<...>'
# marks values to be captured per java/MIGRATION_NOTES.md section 1.6.
