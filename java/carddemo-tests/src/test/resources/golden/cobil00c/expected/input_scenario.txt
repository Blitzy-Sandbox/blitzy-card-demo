#  11. CONFIRM='N' -- CLEAR-CURRENT-SCREEN; no payment
#  12. CONFIRM='Y' happy path -- WRITE TRANSACT + REWRITE ACCTDAT; success (DOUBLE SPACE)
#  13. CXACAIX NOTFND on Y-path -- second 'Account ID NOT found...' site
#  14. Auto-trigger via CDEMO-CB00-TRN-SELECTED populated -- auto-PERFORM PROCESS-ENTER-KEY
#
