Security Modernization

From Plaintext to Hardened, Stateless Auth

Before
  • File-based USRSEC with plaintext passwords.
  • CICS conversational state carried in COMMAREA.
  • Terminal/PF-key driven access control.
After
  • BCrypt password hashing (constraint C-003 permits the upgrade).
  • Stateless JWT Bearer tokens — no server session.
  • Spring Security 6 SecurityFilterChain; roles ADMINUSER

No hardcoded credentials: all secrets flow through environment variables or vault references.
