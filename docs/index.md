# CardDemo Modernized Walking Skeleton

Welcome to the documentation for the **CardDemo modernized walking skeleton** — the
target-state topology (services, API contracts, data wiring, UI shell, CI/CD, and
deployment unit) that **builds green** and runs exactly **one** live vertical tracer
slice end-to-end, while every remaining capability is present only as a typed
placeholder stub. This is a **structural / topology run**: success is defined by the
seams holding together and the single tracer being live, not by behavioral parity
with the legacy application.

> **This page and the `Skeleton (Authoritative)` section are the authoritative
> documentation for this repository.** The `Archived — Superseded Design` pages
> (`project-guide.md`, `technical-specifications.md`) describe an earlier,
> superseded design and are retained only as historical context — see the
> supersession note below.

## Pinned Target Stack

- **Java 21 + Spring Boot 3.5.x** — seven bounded-context domain services plus one
  thin **BFF** aggregation service (**eight Spring services total**).
- **Oracle Database 23ai** via `gvenzl/oracle-free` (PDB **`FREEPDB1`**, port 1521,
  an explicit pinned image tag — never `latest`); JDBC driver **`ojdbc11`**.
- **JPA / Hibernate `OracleDialect` + Flyway** migrations; surrogate primary keys
  via `GENERATED BY DEFAULT AS IDENTITY` (seed-safe); the `CARD` table is keyed on
  the natural `CARD_NUM`.
- **OpenAPI 3.1** contract-first codegen — a **frozen** single source of truth under
  `/contracts/**`; Java server interfaces (`spring`, `interfaceOnly`) and a
  `typescript-axios` UI client are generated from it.
- **React 19 + TypeScript + Vite + MUI v9** SPA (`@mui/material` core + Emotion) that
  binds **only** to the thin **BFF**.
- **docker-compose** as the single-VM deployment unit (**no Kubernetes, no
  serverless**); startup gated by `depends_on: condition: service_healthy`
  (Oracle → Flyway → request-serving services; `reporting-svc` exempt).

## The One Live Tracer Slice

An authenticated request flows **UI → BFF → `card-svc` → Oracle `FREEPDB1`** (a
seeded row) → a rendered **Card Detail** screen, with real loading, empty, and error
states. The tracer is sourced from the legacy Credit Card View path
`[SRC: COCRDSLC | CARDDAT]`. Everything else is a typed `[DEFERRED]` stub.

## Supersession Note

For the skeleton run, the run contract is authoritative and the `docs/skeleton/**`
set is the authoritative documentation. It **supersedes** `docs/project-guide.md` and
`docs/technical-specifications.md`, which describe a materially different, superseded
target — **Java 25 / Spring Boot 3.5.x on PostgreSQL 16** with **AWS S3/SQS/SNS (via
LocalStack)**, **Spring Batch**, a **Micrometer / Jaeger / Prometheus / Grafana**
observability stack, and a **REST-only** backend with the browser UI explicitly
excluded. The run contract instead pins **Java 21 / Spring Boot 3 on Oracle 23ai**, a
**React 19 + MUI SPA + BFF** UI tier, **OpenAPI-generated** clients, and a
**docker-compose single-VM** deploy. This follows the AAP §0.1.2 conflict-resolution
note. Those superseded pages are grouped under **Archived — Superseded Design** and
each carries a prominent superseded banner.
